# La Gruta — Website

Landing page for La Gruta, a fashion and art boutique in Barcelona.

## Direction

Editorial fashion aesthetic with the boutique's colorful, retro graphic identity. Warm ivory backgrounds, forest green typography, and accents in burgundy, pink, orange, and yellow.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Motion for subtle interactions

## Scope

A multilingual (Spanish, Catalan, English) landing page focused on brand discovery, featured collections, the boutique story, Instagram, and the physical store. This is not a full e-commerce checkout.

## Development

Install dependencies with `npm install` and run `npm run dev`.

Store details, opening hours, and contact information must be confirmed before launch.
